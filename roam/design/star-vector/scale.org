synthetic inputs. Include errors, zero vectors, non-unit embeddings, ties,

from database/API work, and report JSON, validation, transport and durability.

* Exact cosine optimization experiment gate

The baseline C ABI over 50k x 128 transient rows passed all 1000 query ID
oracles, with p50 30.35 ms and p95 33.74 ms. The 50k x 1536 cell passed
100 query oracles at p50 261.60 ms. These preliminary timings include some
overlapping setup work and are not the final paired performance claim.
Source inspection shows four vector reductions per cosine candidate:
zero-candidate norm, query norm, second candidate norm, and dot product.

Admit the narrow experiment: compute the unchanged float64 query norm once
per search and reuse the candidate norm computed for zero exclusion. Keep
each reduction order, division expression, error behavior, ID ties and
storage format unchanged. Retain only after independent numerical checks
and sequential matched baseline/candidate runs. No persisted norm cache or
ANN sidecar is introduced by this experiment.
