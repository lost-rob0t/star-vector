* Inference

- Exact linear search is the smallest correct first index. It supplies deterministic reference behavior against which approximate indexes can later be tested.
- Schema and portable-manifest artifacts should be pinned and mechanically synchronized, then embedded in the library so consumers do not need a second runtime service.
- A JSON-returning C ABI avoids exposing Nim layouts or allocator-owned aggregate structures.

* Contradictions

- The older sibling =starintel-doc.nim= checkout is pinned to the historical 0.9 schema and cannot validate the active 0.10.1 lowerCamelCase contract.
- =sbcl.withPackages= currently fails under the pinned nixpkgs wrapper safety gate; direct SBCL package derivations work.

* Unresolved Questions

- Approximate nearest-neighbor indexing is intentionally deferred until the exact-search contract and benchmark corpus exist.
- Cross-process concurrent writers are not part of this slice; atomic replacement protects completed writes, while callers must serialize writers.

* Findings

- Store complete StarIntel JSON alongside embeddings so search results preserve provenance and document identity.
- Validate documents from canonical schema plus portable manifest instead of maintaining a hand-written dtype registry.
- Support cosine similarity, dot product, Euclidean distance, and Manhattan distance with stable ID tie-breaking.
